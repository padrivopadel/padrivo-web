# PADRIVO PADEL
Portada Next.js del repositorio oficial https://github.com/padrivopadel/padrivo-web.

## Ejecucion
Desde esta carpeta, con Node compatible con Next.js (>=20.9 segun lockfile):
```sh
npm ci
npm run lint
npm run build
npm run dev
```
Abrir http://localhost:3000. No hay variables Supabase requeridas para esta portada estatica.
